# 🎮 Tic-Tac-Toe in Python

A simple **Tic-Tac-Toe** game built using Python! This project is a great way to practice Python basics, logic building, and working with the terminal.

---

## 📌 Features

- Two-player mode (Player X vs Player O)
- Command-line interface
- Detects win or draw
- Clean and easy-to-read code

---

## 🛠️ Tech Stack

- **Language**: Python 3
- **Environment**: Terminal / Command Line
